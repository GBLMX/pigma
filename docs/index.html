boxpigma.

终端里的网易云音乐客户端。

在 TUI 里登录、搜索、听歌与管队列：流式播放与边听边存、逐字歌词、多源 fallback， 键盘与鼠标一套操作逻辑，封面走终端的图形协议。

特性

从播放、界面到集成，当前版本已具备的能力如下。

流式播放与边听边存

边下边播，低延迟 seek，也能直接放本地音频；开启边听边存后播放即写入缓存（下载管理与它共用一套）。

多源 fallback

官方源拿不到时依次走 kugou / kuwo / bilibili / youtube，都不需要 cookie。

歌词五种样式 + 逐字

window / one_line / ktv / flow / plain，配合逐字扫光高亮；译文可随原文开关。

歌手页三栏

热门曲目、专辑、相似歌手同屏，三栏共用一个光标，键盘与鼠标的行为一致。

推荐生态

每日推荐、相似歌曲、包含该歌的歌单、听歌排行（本周 · 全部）、推荐电台、私人 FM 都接进侧栏与内容页。

音质与音频链

八档音质（standard / higher / exhigh / lossless / hires / jyeffect / sky / jymaster），解码之后到设备之前可挂 rubato 重采样、参量 EQ、EBU R128 响度归一化；Windows 上走 WASAPI 独占，设备拒绝时回退共享模式。

终端图形协议封面

kitty 图形协议画封面并做圆角裁切，用哪个协议以终端的回答为准，tmux 里自动回退。

主题系统

内置 20 套主题，[themes.<名>] 按组件继承式自定义；仓库带 theme.schema.json，编辑器里能校验与补全。

设置页与 vim 风格命令

, 或 :settings 开设置页；: 打开命令行并支持 Tab 补全，:theme、:lyrics、:simi、:fm 都能运行时改。

CLI 控制与 JSON IPC

boxpigma status / msg 查询与控制一个正在运行的实例（waybar 之类都能接），配合 -d 守护进程模式即可无终端常驻。

系统包管理器安装

yay / paru / scoop 走各家包管理器，另有 bash / zsh / fish / elvish / powershell 的 shell 补全。

单一 Cargo workspace

两个 crate 收进一个 workspace，cargo test/clippy --workspace 覆盖全部成员；CI 覆盖 Linux、macOS、Windows 三平台并检查 workspace 成员。

安装

下面两条命令从本仓库的 release 下载，并校验随发布附带的 SHA256SUMS。

Linux / macOS

curl -fsSL https://raw.githubusercontent.com/GBLMX/pigma/main/install.sh | sh

脚本按 uname 判定平台，默认装到 ~/.local/bin；先看一眼它要做什么可以加 --dry-run。

Windows / PowerShell

irm https://raw.githubusercontent.com/GBLMX/pigma/main/install.ps1 | iex

也可以从 releases 直接下载 boxpigma-x86_64-pc-windows-msvc.zip 解包使用。
